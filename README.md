# 🎨 CIE 1931 色度图交互分析工具

这是一个轻量级、单文件的 Web 应用程序，用于在浏览器中可视化和分析 CIE 1931 色度图。该工具无需服务器环境，直接在浏览器中打开即可运行，集成了色彩空间叠加、光谱数据计算和自定义坐标标注功能。

**渲染引擎**：原生 JavaScript + HTML5 Canvas API，无第三方库依赖。

**访问链接**：https://lizhiq16.github.io/CIE1931/CIE1931.html

## ✨ 主要功能

*   **📊 动态可视化**：基于 HTML5 Canvas 实时渲染 CIE 1931 色度图，支持平滑缩放和重绘。
*   **🌈 标准色域叠加**：支持一键叠加显示主流色彩空间的色域三角形，包括：
    *   **sRGB** (Rec.709)
    *   **DCI-P3** (数字电影)
    *   **Rec.2020** (UHDTV)
*   **📈 光谱数据计算 (CSV)**：
    *   支持导入本地 CSV 格式的光谱功率分布数据。
    *   自动基于 CIE 1931 2° 标准观察者数据进行积分计算，得出精确的 $(x, y)$ 色度坐标。
*   **📍 自定义标注**：
    *   支持手动输入 $(x, y)$ 坐标添加自定义标记点。
    *   实时显示标记点的 RGB 预览颜色及具体坐标数值。
*   **🛠️ 高度可配置**：
    *   支持自定义画布尺寸（宽高）。
    *   支持调整标题、坐标轴、波长标注及标记点的字体大小。
    *   支持显示/隐藏网格线、坐标轴及光谱波长刻度。

## 📖 使用指南

### 1. 图形与视图设置
在左侧控制面板的“图形与坐标系设置”区域：
*   **显示坐标轴/网格**：勾选以显示或隐藏背景网格和 X/Y 轴刻度。
*   **波长标注**：勾选以在马蹄形光谱轨迹上显示纳米 (nm) 波长数值。

### 2. 标准色域叠加
在“标准色域叠加”区域，勾选相应的复选框即可在图表中绘制色域三角形：
*   **sRGB**：绿色线条，最常用的标准。
*   **DCI-P3**：黄色线条，广色域标准。
*   **Rec.2020**：红色线条，超广色域标准。

### 3. 载入光谱数据 (CSV)
点击“选择并载入 CSV 光谱文件”按钮导入数据：
*   **文件格式**：CSV 文本文件。
*   **数据格式**：文件需包含两列数据。
    *   第 1 列：波长 (nm)，范围建议 360-770。
    *   第 2 列：相对强度 (任意单位)。
    *   分隔符支持：逗号、分号、空格或制表符。
*   **计算逻辑**：程序会读取 CSV 数据，结合内置的 CIE 1931 标准观察者函数 ($\bar{x}, \bar{y}, \bar{z}$) 进行加权积分，计算出三刺激值 $X, Y, Z$，进而转换为色度坐标 $(x, y)$。

### 4. 手动坐标管理
*   **添加点**：在输入框中输入 `x` (0.0-0.8) 和 `y` (0.0-0.9) 的值，并填写标注名称，点击“添加自定义点”。
*   **管理列表**：下方列表会显示所有已添加的点，包含颜色预览和坐标。点击“删除”可移除单个点，点击“清空所有点”重置列表。

### 5. 绘图尺寸与字体
支持实时调整画布分辨率和各类文本的字体大小，调整数值后图表会自动重绘以适配新的样式设置。
